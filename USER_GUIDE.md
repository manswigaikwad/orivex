### Horizontal Scrolling
This website uses **horizontal scrolling** for an immersive storytelling experience.

- **Navigation Dots**: Click any dot at the bottom to jump to a section
- **Keyboard**: Use arrow keys (← →) to navigate
#### Mobile/Tablet Navigation
- **Swipe**: Swipe left/right to navigate between sections
- **Touch**: Tap the navigation dots to jump to sections
- **Arrows**: Use the on-screen arrow buttons

### Troubleshooting
**Website not scrolling:**
- Refresh the page
- Check browser compatibility
- Clear cache and cookies
- Try different browser


**Form not submitting:**
- Check required fields
- Verify internet connection
- Disable ad blockers
- Try again after 5 minutes


**WhatsApp button not working:**
- Check if WhatsApp is installed
- Verify phone number format
- Try opening in browser
- Use alternative contact method
